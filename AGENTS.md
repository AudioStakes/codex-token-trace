# codex-token-trace

`codex-token-trace` is a local-first CLI for analyzing Codex session JSONL logs and tracing token usage.

## Quick Reference

- Package manager: `npm`
- Build: `npm run build`
- Dev: `npm run dev -- <command>`
- Test: `npm run test`
- Fix: `npm run fix`
- Verify: `npm run verify`
- Prefix shell commands with `rtk`
- Use concise, direct replies
