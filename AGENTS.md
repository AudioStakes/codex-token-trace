# codex-token-trace

`codex-token-trace` is a local-first CLI for analyzing Codex session JSONL logs and tracing token usage.

## Quick Reference

- Build: `npm run build`
- Dev: `npm run dev -- <command>`
- Test: `npm run test`
- Use concise, direct replies
