# Delivery

## Overview

Keep handoff and repo workflow explicit.

## Rules

- Before finishing work, commit the final changes.
- Push the current branch.
- Create a pull request or update the existing one.
- If you are on `main`, switch to a non-`main` branch before committing.
- Final user-facing reports should include what changed, the PR URL or updated PR, any ADRs added or why none were added, any `CONTEXT.md` terms added or why none were added, and any follow-up work that remains.
- Keep user-facing replies concise and direct.
